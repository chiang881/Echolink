# WebRTC Audio Sync System | [English](README_EN.md) | [中文](README.md)

这是一个基于 WebRTC 技术的多设备音频同步播放系统，支持多个设备之间的实时音频同步播放功能。

## 功能特点

- 🎵 支持多设备音频同步播放
- 🔄 主机-客户端模式
- 📱 支持手机扫码快速加入
- ⚡ 自动延迟校准功能
- 🎧 支持本地音频文件和网页声音捕获
- 🔧 手动延迟微调功能
- 📊 实时延迟显示
- 🔗 设备连接状态监控

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- WebRTC (PeerJS)
- QRCode.js
- HTML5-QRCode

## 快速开始

1. 打开网页应用
2. 选择模式：
   - 主机模式（电脑端）
   - 客户端模式（手机端）

### 主机端操作

1. 点击"我是主机"按钮
2. 获取邀请码或展示二维码
3. 选择音频来源：
   - 上传本地音频文件
   - 捕获网页声音
4. 等待客户端连接
5. 使用校准功能调整延迟
6. 开始播放音频

### 客户端操作

1. 点击"我是客户端"按钮
2. 通过以下方式加入：
   - 扫描二维码
   - 输入 6 位邀请码
3. 等待连接成功
4. 同步接收并播放音频

## 特殊功能说明

### 延迟校准

- 自动校准：点击"校准延迟"按钮进行自动延迟测量和调整
- 手动校准：可通过输入框手动微调延迟值（-1000ms 到 1000ms）

### 设备管理

- 实时显示已连接设备列表
- 监控设备连接状态
- 显示每个设备的延迟情况

## 注意事项

1. 确保所有设备都连接到同一个网络
2. 主机端建议使用电脑以获得最佳性能
3. 客户端支持移动设备访问
4. 使用现代浏览器以确保 WebRTC 功能正常工作

## 系统要求

- 现代浏览器（支持 WebRTC）
- 稳定的网络连接
- 音频播放设备
